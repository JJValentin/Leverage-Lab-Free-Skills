# Sources and evidence register

This skill is a research-informed synthesis rather than a standards-compliance implementation. Core foundations used by the architecture include NASA systems engineering (verification/validation), Kanban flow/WIP management, Donella Meadows on systems and feedback, NIST AI RMF, OWASP Excessive Agency, Agent Skills packaging, Anthropic guidance on effective agents/context/long-running harnesses, Nielsen usability heuristics, Microsoft HAX, Galbraith's Star Model, and Malone & Crowston on coordination theory.
