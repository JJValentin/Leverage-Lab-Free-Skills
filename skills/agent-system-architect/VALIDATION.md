## Deployment gate

The shipped contract examples use `shadow` mode, `external_transmission_enabled: false`, `evaluation_status: not_run`, and unset thresholds. The system-spec template defaults decisions off. The helper returns `applied: false` and `authorized: false` even when fixture gates pass. An authorized deployment must separately establish data egress, current source reads, error calibration, per-action permission checks, bounded costs, fallback and user-value acceptance.

A skill-directory update is not a runtime installation or a GitHub publication. This delivery changes only downloadable artifacts.
