# Harness adapters

Treat filenames as implementation details, not architecture. For every harness first verify version, active profile/home, instruction precedence, skill roots, memory provider, task/work store, tools, scheduler, permissions, delegation, and resumption behavior.

## Hermes
Resolve the actual profile/HERMES_HOME and configured skill roots. Preserve the existing memory provider and native Kanban/work coordination. Temporary delegation is not the same as durable work ownership. Keep Project Hub as a reader view, not a second task board. Do not create a Jev profile; bounded decisions should be an optional tool/workflow step.

## OpenClaw
Map the operating model to the verified workspace, skills, memory, channels, tools, and agent boundaries. Do not treat a workspace name as proof of host isolation or credential separation.

## pi coding agent
Use its supported instruction/skill/session mechanisms. Do not assume native subagents, permission popups, durable scheduling, or memory beyond what the installed extensions actually provide.

## Claude Code
Use the verified `.claude/skills/` roots and CLAUDE.md/project instruction mechanisms. Use subagents only for justified isolated work. Verify inherited tools/context and do not confuse authored instructions with auto-memory or runtime authority.

## Codex
Use current `.agents/skills/` discovery and current subagent configuration supported by the installed release. Keep project instructions, skills, workers, approvals/sandboxing, and any memory/continuity mechanism distinct.

## Other harnesses
Map capabilities, not filenames: instructions, reusable methods, durable facts, project record, task coordinator, tools, approvals, scheduler, temporary workers, persistent identities, artifact store, and front-door UX. Missing capabilities should reduce autonomy or use an existing external mechanism rather than being simulated in Markdown.

For the optional decision layer, the same contract/input/typed-observation/fallback boundary applies across harnesses. No provider account, plugin, daemon, global memory, or per-turn hook is required by this skill.
